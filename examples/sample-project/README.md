Key focus areas and capabilities of this project:

- **weather**: Core topic and functionality
- **forecast**: Core topic and functionality
- **terminal**: Core topic and functionality
- **cli**: Core topic and functionality

## Installation

Install globally via npm:

```bash
npm install -g weather-cli
```

Or run directly without permanent installation via npx:

```bash
npx weather
```
